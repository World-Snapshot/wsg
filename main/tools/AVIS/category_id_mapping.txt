AVIS Category ID Mapping
========================

This file documents the AVIS category ids used by the AVIS train/val/test
annotation JSON files. Pipeline 29 writes these integer category ids into
WSG/WSV channel 195 inside each AVIS instance mask.

Channel 195 semantics after pipeline29:

- -1: no AVIS instance / invalid background
- positive integer: AVIS semantic category id for the instance covering that pixel

Important note:

Channel 195 is a semantic category map, not an instance-id map. If two people
are visible in the same frame, both person regions are written as category id 1.
The channel does not distinguish "person 0" from "person 1".
